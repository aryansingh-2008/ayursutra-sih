# AyurSutra — Smart Panchakarma Care Platform

AyurSutra is a role-based Panchakarma clinic prototype combining patient 360 care coordination, explainable AI-assisted decision support, and conflict-aware smart scheduling.

### SIH differentiators
1. Explainable AI therapy-ranking copilot
2. Safety/review prompts and clinician-in-the-loop approval
3. Smart scheduling across patient + therapist + room constraints
4. Doctor reassignment without losing clinical history
5. Protocol library connected to the actual clinic therapy catalog
6. Progress/adherence insight and operational analytics

See `UPDATED_FOR_SIH.md` for the complete demo flow and setup.
